# ♾️ Loopin V2 — Tasarım Sistemi ve UI Standartları (DESIGN_SYSTEM.md)

---

## 1. Tasarım Felsefesi

Loopin V2 görsel dili, karanlık mod (dark theme), neon parlamalar (ambient glow) ve cam efektleri (glassmorphism) üzerine kurulmuştur. Kullanıcı prototipi gördüğünde hissettiği modern ve dinamik sosyal deneyim %100 korunmuştur.

---

## 2. Renk Paleti (Color Tokens)

| Token | Değer | Kullanım Alanı |
|---|---|---|
| `--color-bg` | `#0A0A0A` | Ana ekran arka planı |
| `--color-surface` | `#1A1A1A` | Kartlar, modallar, açılır pencereler |
| `--color-surface-2`| `#2A2A2A` | İkincil butonlar, girdi alanları |
| `--color-primary` | `#6366F1` | Vurgu, birincil butonlar, logo ışıması |
| `--color-secondary`| `#10B981` | Çevrimiçi durumu, başarı bildirimleri |
| `--color-accent` | `#F59E0B` | PRO rozetleri, dikkat çekici etiketler |
| `--color-error` | `#EF4444` | Hata durumları, silme/iptal etme |

---

## 3. Tipografi (Typography)
- **Başlıklar (Headings)**: `Outfit` (Google Fonts, 700 / 800 weight)
- **Gövde Metinleri (Body Text)**: `Inter` (Google Fonts, 400 / 500 / 600 weight)
